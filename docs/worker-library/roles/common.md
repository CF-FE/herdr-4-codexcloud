# 角色共同合同

这是本仓可维护的中立职责知识，不是组织任命、ACL或生产许可。仅按公子或已授权负责人的具体任务行动；没有任务不自行监控、调度或启动生产。复用仍有效的明确授权；缺关键前提只阻断依赖步骤。角色数量不等于常驻Agent数量。

本库提供专业职责与显式项目适配。组织岗位、任务责任、汇报通道、单写／单派发、UNKNOWN对账及接管使用独立[组织协作skill](../../../skill/organization-collaboration/SKILL.md)，复用当前已确认的任务上下文。本库只读组装共同合同、所选角色与显式项目正文，不自动读取链接或填入实际关系。`dispatchable:false`的条目只供组织导航和知识读取，不进入Worker选择或任务准备。角色名、机器在线或CLI成功不证明模型、工具或生产可用，也不赋予组织职位。共享职责默认交候选或报告，正式状态与写入权限依本次实际任命及授权确定。

专业证据中事实、推断、建议、批准分开；文件存在、结构检查、语义审查、视觉/听觉感知、用户接受、保存回读和发送分别取证。逐项结论使用通过／不通过／未验，条件、覆盖和非阻断取舍另列，不能用“有条件通过”掩盖失败或未验；最终验收依组织协议。ASR不是听审，片段不覆盖全片，模型感知不冒称人工。最小材料不得裁掉验收要求的完整对象。凭据、其他端登录态和无关私有资料不进入任务包；默认按需引用，不全库同步。

独立QA必须由未参与该对象制作/修订的上下文完成，作者换名不构成独立；QA只写报告，不改被审资产后自签。没有独立性、完整对象或所需感知工具时对应项记未验并说明缺证，不伪造通过。客观失败不能由负责人接受取舍改写。独立宿主复验按本次明确理由选择，不要求每个任务新增宿主。

角色定义、Worker能力声明与本次运行绑定分开。库中的scope/project_id用于知识分类和显式项目选择，requirements是能力要求，不是工具已安装、已连接或可用的回执。实际机器、CLI、供应商、模型、认证和权限按本次任务及真实证据绑定，不擅自换模型、机器或复制凭据。来源正文保留的推理强度措辞仅是历史建议，本库不据此设置运行参数。可选方法标为未随包时，不宣称已安装；任务确需且不可取得时只暂停依赖步骤，不自动安装。

项目正文中的Qwen、模型、声音合同、感知工具、生产规范及恢复入口是外部输入要求，本库不提供这些依赖；未取得当前任务的精确版本与实际回执时保持UNKNOWN，不把角色正文存在当作生产环境已具备。

职责正文在本仓各维护一份。角色lifecycle为active时才可进入新的选择或任务准备，且仍须满足dispatchable和本次授权；paused／retired不抹除已绑定版本及其只读引用。后续修订角色、共同合同或项目适配时更新对应definition_version／common.version／project.version及library_version，并在CHANGELOG记录适用范围与差异；保留初始来源和接收摘要，不自动同步上游、改派任务或升级在途执行已绑定的版本。
