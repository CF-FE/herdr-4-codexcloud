# 给 Dot：Mac 上 Herdr 项目协作层的限定评估需求

原需求日期：2026-11-02；整理日期：2026-11-03（Asia/Shanghai）。本页专门验证 **云端Dot → 其获权的Mac原生任务 → Herdr → Codex／Kimi → 原任务返回Dot**，由公子按需要转交。通用准备、UNKNOWN和退出规则见[试点指引](pilot.md)，当前证据见[状态](status.md)。文档修订不触发评估、追加回合或重派未决请求。

桌面Lead显式调用已有Mac Codex的[适配器首版验收](herdr-executor.md#验收记录)已经通过；它不能证明Dot自己具备原生Mac任务入口、Kimi回合或结果回收能力。本页E0—E5保持独立范围，不借用该样本记为通过。

## 2. 执行范围与预算

以下仅保留原E0—E5评估的上限，不能与后来适配器的单次smoke预算相加或据此再发一次请求；承接时先核原任务已有执行与剩余预算。

| 原评估边界 | 上限 |
| --- | --- |
| 文本回合 | Codex 1个＋Kimi 1个，总计最多2个；不补问、重发、换模型或委派子任务 |
| 总观察窗口 | 最多15分钟 |
| 原生任务／状态／列表／结果查询 | 合计最多20次；本地help／version另计 |
| 单模型回合观察 | 最多120秒，在总窗口与查询预算内；不追加后台轮询 |
| 文件与外部效果 | 无业务文件修改；只在已有获准落点保存本次报告／证据，不登录、安装、改认证／网络或启停系统服务 |

本页不覆盖Win、Cloud、VPS操作、Lody迁移、真实项目或多项目负载。缺前提和停止处理直接使用[通用规则](pilot.md#退出与采用)，不因某一分支受阻重启其他已完成分支。

## 3. 入口与目标绑定

1. Dot从自身原生工具取得准确Mac task／request引用、设备与目录，核该任务当前允许范围；他人代查必须标源。
2. 若原投递超时或状态不明，先查原任务和已发生效果。没有原引用不能以新任务替代对账。
3. Herdr参数按目标版帮助核对。仅在原评估有效授权内创建独立命名测试session，或使用明确移交且无未决工作的专用目标；保存返回ID，不复用已清理的旧ID。
4. 区分外部Dot的获准系统CLI入口与窗格内Agent的官方技能条件。不得伪造`HERDR_ENV`或pane身份，也不操作既有业务pane或默认session。

模型、认证及权限使用已有获准配置。Kimi如明确认证拒绝，该认证项记FAIL、尚未发起的E3记NOT_RUN；不为补齐结果重新登录或换供应商。

## 4. 有界测试步骤与通过条件

| 步骤 | Dot需取得的证据 |
| --- | --- |
| E0 原生入口 | 自身工具回执关联准确Mac task；设备在线列表不能代替任务可执行 |
| E1 Herdr控制 | 本次专用shell pane中的确认命令产生独立nonce整行输出及退出码；创建、提交和输入回显不算完成 |
| E2 Codex | 实际Agent／pane对应，单次请求生成与该nonce对应的新响应；排除启动页和旧输出 |
| E3 Kimi | 与E2相同，但以其自身模型／认证与回执独立判断 |
| E4 Dot回收 | Dot沿原Mac任务实际读取E1—E3结果；发送、受理、完成通知与原任务终态分别对应 |
| E5 查询／清理 | 只清理本次真实ID绑定且已结束的资源；保留前后列表或明确承接，不能用强制关闭抹掉UNKNOWN |

E1可把`printf`格式与nonce分开，使最终整行输出不原样出现在输入中。E2／E3使用不同的三个随机片段，要求倒序输出一个ACK行；完整预期由测试方独立计算，不放进prompt。每侧仅一请求，不用追加提问修补证据。

模型请求限定不调用工具、联网、写文件或委派；实际工具效果仍按原生记录核验，不因prompt写了禁止就填0，不可读时记UNKNOWN。两侧无需并发。若清理查询使原任务重新活动，最后重新核其终态，不能沿用旧completed。

## 5. 必须保留的证据与停止规则

在[通用任务模板](templates/pilot-task.md)之外，每步追加 `test_id/step_id`、实际观察者／入口、Mac task／request、Herdr原生引用、nonce及预期／实际摘要、提交／受理／生成／读取时点、外层工具状态与真实退出码。实际私密ID及映射留在获准证据中，公开报告使用稳定别名。

停止与UNKNOWN对账沿[试点规则](pilot.md#等待未知与恢复)。本页特别保留：Dot投递timeout不能当作未受理；idle／interactive_ready／completed各按原生含义记录；超出剩余预算即报告已有事实，不为凑失败或成功样本二发。

## 6. 请返回的报告

沿原任务交付一份可读报告，必要时附JSON；无文件写权就直接返回结构化正文，不另开存储。报告按E0—E5列 `PASS/PARTIAL/FAIL/UNKNOWN/NOT_RUN`、证据归属、实际调用／模型次数、输入输出关联、测量时钟、未决资源与下一责任人。原始证据和脱敏报告分别引用，凭证与私密连接配置不进入报告。

本地命令耗时、入口往返与模型等待分开；未知费用／内部请求数不填造。只有E0—E4证据完整且资源安全收尾或有效交接，才可将**这条限定Dot原生链路**记为PASS。Codex／Kimi任一侧缺失则总体最多PARTIAL；Dot未实际读回不能称端到端完成。最终返回公子，不代为发布或切换项目入口。
