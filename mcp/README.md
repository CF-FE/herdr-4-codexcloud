# MCP 服务

当前没有 MCP 服务条目。已有技能使用目标宿主实际提供的工具，不在本仓隐式安装或共享其他仓库的服务。

当前信箱服务已按公子要求完整纳入 [create-network-sh/fastmcp/task-mailbox](https://github.com/ghyghoo8/create-network-sh/tree/main/fastmcp/task-mailbox)，原 [CF-FE/task-mailbox-mcp](https://github.com/CF-FE/task-mailbox-mcp) 保留首次来源。固定提交、逐文件摘要、独立维护与接入证据见[接收说明](https://github.com/ghyghoo8/create-network-sh/blob/main/fastmcp/task-mailbox/INTEGRATION.md)。本仓不保留实现副本或跨仓运行依赖；信箱不自动执行 Herdr。

Dot、Mac Codex／Kimi，以及具体云任务实际具有获准 MCP 工具与认证的 Codex Cloud，可作为同一信箱的主动客户端。当前服务、公网、插件与各客户端真实读写分层记录在[接入快照](../docs/status.md#vps-任务信箱与客户端接入进行中)，不把模板或插件创建当作全端已接通。

有明确接入需求时再新增 `mcp/<id>/`，写清唯一源码、依赖、配置、工作目录及验证方法。整体边界见[架构](../docs/architecture.md)。
