# 白名单维护入口

版本：1.0.0。来源：本仓独立维护的工程 Skill。

先读[场景白名单 README](../../config/allowlists/README.md)，确认当前场景的配置文件、维护责任和交付阶段。具体允许值只在该场景 JSON 中维护；不要从本 Skill、模型缓存或旧聊天另建名单。

从配套仓库根按维护指南运行[离线工具](../../scripts/allowlists.py)。`validate` 检查场景策略，`preview` 按给定能力证据核对匹配与排除项，`defaults` 查看 Agent 场景的环境默认值及来源。沿原任务记录策略修订号、摘要、检查结果和接线状态。

Mac Codex `new-unit` 在候选筛选和启动前执行策略校验。原单已有启动意图时沿冻结记录对账。Win、Cloud 的原生模型参数和图像调用各有待接入口。核对实际发布与宿主采用时，查看[当前状态](../../docs/status.md#当前结论)和原部署回执。

本文件是仓库源码中的导航入口。策略更新、发布与接线沿维护指南和原任务授权办理。
